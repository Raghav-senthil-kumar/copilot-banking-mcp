# Copilot Banking MCP

A simple Python bank application sample project created for GitHub Copilot MCP demonstration.

## Features

- `depositAcc`: deposit funds into an account
- `withdrawAcc`: withdraw funds from an account
- `transfer`: transfer funds between accounts
- custom `InsufficientFundsError` exception for insufficient funds

## Usage

Run the application with:

```bash
python main.py
```
